fal.ai parallax playground — gradient sky + clouds layer

Fixed-frame scrollytelling: the hero is position: fixed and never moves; the scene canvas inside it slides up with scroll (sinkPx = progress * travel, reproducing the old sticky window) while the layers parallax inside it driven by progress = clamp(scrollY / travel, 0, 1) with the same tuned start/end values as before. travel is 75% of the viewport height minus a 0.5cm pad, so the end state leaves a scene strip of exactly 25% of the viewport on every screen. Layer geometry is stored as fractions of a 1170px reference hero and re-fitted to the measured canvas height on resize, so browser zoom re-fits the composition instead of breaking it. The scene width is capped at 2048px (CSS px, centered) with plain dark beyond. Tree-bark side edges at min-width: 768px as a silhouette-only feTurbulence-displaced SVG mask against the plain background, sitting at the cap boundary on ultra-wide screens. The bottom fade is anchored to this content's leading edge: it turns solid just above the panel at every scroll depth, so the panel always emerges from solid dark, and it stays put once progress hits 1 while the text scrolls over the dark zone. The canvas keeps the tuned 130svh geometry on wide screens (100svh below 768px). Sky is a CSS gradient sampled from sky.png; it parallaxes via the sky row (background-position on the container). Clouds are their own layer (clouds.png, in front of the mountain for occlusion, anchored left bottom below 768px) and share the sky values to stay registered on the gradient. The foreground is trans-foreground-s85.png (the original translucent foreground; the solid/leveled experiments were cancelled and their files kept in this dir for later). Parallax math: each layer translates start + (end - start) * progress. The tuning panel (bottom right) ships Philip's tuned defaults: sky -100/217, mtn -213/247, clouds -124/182, hill-river -103/202, city -82/79, fg -91/-67. Drag sliders to retune; the readout line is the compact format to paste back.
