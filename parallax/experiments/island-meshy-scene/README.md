# Animated island experiment

Open `index.html` in a browser. This is a standalone preview, not the homepage. It keeps the optimized Meshy split model separate from the site's current hero.

The island rotates slowly in a shader-based water plane with an oval fade, with flickering firelight, a glowing lantern, flame geometry, smoke sprites, embers, continuously drifting clouds at randomized heights, an illustrated moon, and softly twinkling SVG stars. A separate 3,656-byte Draco mesh adds glasses and simple facial features without changing the original model. The monitor uses the model’s original screen texture, and the desktop has a subtle procedural wood grain. A user-controlled 15-second campfire sound loops when enabled. The sound is adapted from the public preview of [Camp fire by RCSound99](https://freesound.org/people/RCSound99/sounds/654043/), released under CC0. The preview was trimmed, crossfaded, and encoded as mono MP3 at 32 kbps (60,412 bytes). The sky spans the viewport, while the water fades around the island. The extra page height is for scroll testing. The generated cloud sprite sheet and moon total about 82 KB. Swipe or drag horizontally to turn the island; automatic rotation resumes four seconds after release. Arrow keys also turn the island. Meshy's split grouped the seated developer and chair together; the idle animation (slow breathing, a nod to the music in his headphones, and a glance toward the fire every 16 seconds) uses position-weighted vertex deformation at runtime, not a skeletal rig. The legs are part of the ground mesh, so the chair does not swivel. The water ripples wobble and break into segments instead of forming perfect circles. The preview loads a Blender-edited copy with a five-caster chair base, cleared ground fragments, original shirt sleeves, and adapted low-poly hands by Anastasiia Ku fitted at the cuffs. The original split model and the prior repaired model remain unchanged. Fingers and mouse are not separately animated. The flame, water, character movement, and island rotation stop when the user pauses, prefers reduced motion, the tab is hidden, or the canvas is offscreen. The renderer caps pixel ratio at 1.25 and updates at most 30 frames per second.

`island-touchups.glb` is the current model used in the preview. It is `island-desk-flattened.glb` with three texture and vertex fixes: the round tab and the grey-blue stick at the front of the desk are pushed back to the desk edge, flattened to the desktop height, and given wood texture coordinates, and the bump at the monitor's bottom-right corner is moved back onto the screen and given screen-blue texture coordinates. `island-desk-flattened.glb` is the preceding version, preserved for rollback. It is `island-desk-restored.glb` with the round lump at the front of the desk (fused original geometry) flattened to the desktop height and given wood texture coordinates from the nearby desktop. No faces were deleted, so the desktop stays closed. A thin grey-blue flap from the original fused arm still sticks out from the desk's front edge. `island-desk-restored.glb` is the preceding version, which replaced an edited desk that had a hole with the unchanged original desk mesh (`model_part3`) from `island-split.glb`; it is preserved for rollback. `island-cuffs-restored.glb` is the preceding repair, preserved for rollback. `island-anastasiia-hands.glb` is the preceding repair, preserved for rollback. Its hands are adapted from [Low poly hands by Anastasiia Ku](https://poly.pizza/m/cGaYRuiPCMe), licensed [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The original downloaded hand model is saved as `anastasiia-hands-source.glb`. `island-hands-v3.glb` is the preceding repair, preserved for rollback. `island-repaired.glb` is the previous repair, preserved for rollback. `island-split.glb` is the 324,168-byte Draco-compressed textured model it was based on with approximately 40,177 triangles. It was produced from Meshy auto-split task `01a1dbe6-a43a-7179-87eb-6c8a658160f3` by resizing textures to 1024px, encoding WebP, removing normal and metallic-roughness maps, welding, simplifying (`ratio 0.5`, `error 0.005`), and Draco compression. The full split result is saved outside the repository as `meshy-split-original.glb` in the Atlas quickstart scratch folder. The original unsplit Meshy files are preserved.

The standalone page embeds the model and Draco decoder as base64 JavaScript so it opens over `file://`. A temporary local server with gzip served the previous version of the page and its same-origin resources at about 605 KB transferred including the browser's reported per-resource overhead. The current version has not yet had a hosted transfer measurement. Actual hosting, the rest of the site, cache state, and any future assets will differ. No physical-phone performance measurement has been made.

`scene.js` is the source. The current classic-script `bundle.js` was built with Three.js 0.187.0 and Bun. DRACOLoader's default URLs contain `import.meta.url`; this standalone bundle substitutes `document.baseURI` because it provides explicit decoder data URLs. A site integration should bundle modules normally and serve the model and decoder as binary assets. It also needs a proper static fallback for devices without WebGL, and real-device testing. The current fallback is a text message.
